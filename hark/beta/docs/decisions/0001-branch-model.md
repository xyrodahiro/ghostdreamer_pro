# 0001 Branch model

- Upstream NeoMarkiss/ghostdreamer (main) = original open-beta template.
- This fork, xyrodahiro/ghostdreamer_pro (main) = the Pro line.
- Upstream fixes come in by syncing the fork (git fetch upstream; git merge upstream/main).
- Pro work goes back upstream only by deliberate PR to NeoMarkiss/ghostdreamer.
- Session work on session/<date> or feature/<name>, PR into main. Owner's merge = alignment met.
